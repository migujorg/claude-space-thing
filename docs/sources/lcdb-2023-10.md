# lcdb-2023-10: Asteroid Lightcurve Database (public release)

- **URL:** https://minplanobs.org/MPInfo/datazips/LCLIST_PUB_CURRENT.zip (40 MB; last public release 2023-10-01). Table used: `lc_summary_pub.txt` (34,755 rows with a period).
- **Used by:** the `smallbodies` stage (`sb_physical_sources.parse_lcdb_summary`) → `smallbodies/physical.bin` rotPeriod, rotQuality.
- **Citation:** Warner, B. D., Harris, A. W. & Pravec, P. (2009). The asteroid lightcurve database. Icarus 202, 134-146. DOI:10.1016/j.icarus.2009.02.003.
- **Licence:** free for scientific use with citation (LCDB readme).

## Parsing

Fixed-width text. Column starts come from the header line: the number is right-aligned in columns 0-6, NAME and DESIG start under their headers, the period flag sits under the `F` of `F PERIOD` with the value after it (up to `P DESC`), and the reliability code U is the two characters under ` U `.

## Labels

| LCDB | Meaning (LCDB readme) | Label |
|---|---|---|
| U = 3, 3-, 2+, 2, 2- | unambiguous, or possibly wrong by ~30 % / ambiguous | measured |
| U = 1+, 1, 1- | "may be completely wrong" | estimated (following docs/research/m3-small-bodies.md §3) |
| no U | not rated | estimated |
| U = 0 | later proven wrong | not used |
| period flag `>` or `<` | only a limit | not used |

The code itself is kept per object (`rotQuality`, decoded through the header's `lcdbU`). Objects without an LCDB period fall back to the SBDB `rot_per` (measured; its reliability is not given). The public LCDB is from 2023; newer periods (e.g. from Gaia DR3 or ZTF) are not included.
