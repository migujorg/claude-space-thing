# IAU 2015 Resolution B3: nominal solar radius (`iau-2015-b3`)

**Citation:** Prša, A. et al. (2016). Nominal values for selected solar and planetary quantities: IAU 2015 Resolution B3. *Astronomical Journal* 152, 41. DOI [10.3847/0004-6256/152/2/41](https://doi.org/10.3847/0004-6256/152/2/41). Resolution text: arXiv:1510.07674v1 (fetched, sha256 recorded).

**Used:** R☉ᴺ = 6.957 × 10⁸ m = 695 700 km (`light.json` `sun.radius`). The nominal value is exact by definition and was chosen to match the measured photospheric radius (τ_Ross = 2/3) of Haberreiter, Schmutz & Kosovichev (2008, ApJ 675, L53): 695 658 ± 140 km; it is labelled `measured` with that uncertainty statement. The same resolution's nominal total solar irradiance S☉ᴺ = 1361 W/m² (cycle-23 mean, ±1) is used only as the sanity reference for the HSRS integral.
